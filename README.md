## Projects

**Invoice Automation Pipeline**
Cuts manual invoice entry down to a quick review step. Watches Gmail for incoming invoices, extracts the data automatically, flags anything uncertain for a human to check, and sends a weekly summary so nothing gets missed.
[View repo](https://github.com/Milena-Tanui/invoice-automation-pipeline) · n8n · Claude API · Google Sheets · Gmail

**Team Issue Tracker**
Replaces a manual "email someone and hope they see it" process with a fully automated chain. A form submission logs the issue, confirms with the reporter, and alerts the right person on Slack, no follow up needed.
[View repo](https://github.com/Milena-Tanui) · Zapier · Google Sheets · Slack

**GradeFlow**
Turns raw course material into a ready-to-use, difficulty-calibrated assessment in minutes, cutting out the hours instructors normally spend building tests by hand.
[View repo](https://github.com/Milena-Tanui/gradeflow) · CrewAI · Claude · Replit

**AI News Across Africa**
Runs on its own each week to pull together relevant AI developments across the continent, startups, funding, policy, and tools, so nobody has to track it manually.
[View repo](https://github.com/Milena-Tanui/africa-ai-intelligence-crew) · CrewAI · Python · SerperDev · SendGrid
